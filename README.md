# The Pathfinder Visualization
It's an interactive tool that visualizes how computers generate and solve mazes. Instead of just staring at code, you can watch the computer generate and solve mazes.

Features:
- Auto generate a prefect maze form scratch with various maze generation algorithms.

- Play visuals to see how algorithms searching for the exit inside maze.

- Control the flow and see the pathfinding logic happen step-by-step.

-- It's still in the early stages, but the goal is to make these complex algorithms easy to understand by actually seeing them work.
