Generator Algorithms

DFS: Creates mazes with long corridors and deep branching paths.

Prim: Generates mazes with balanced complexity and multiple paths.

Kruskal: Creates mazes by randomly removing walls between cells.

Wilson: Loop-erasing random walk algorithm for uniform maze generation.

Solver Algorithms

BFS: Breadth-first search - finds shortest path systematically.

DFS: Depth-first search - explores deeply before backtracking.

A*: Heuristic-based search - efficient pathfinding algorithm.

Wall Follower: Simple algorithm - follows walls to find exit.

Dead-End: Elimination - removes dead-end paths progressively.
