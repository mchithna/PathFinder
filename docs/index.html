How to Use

  1. 1 Pick a size — S is great for quick demos; XL stress-tests the algorithms.
  2. 2 Choose a Generator — each algorithm produces a distinct maze character.
  3. 3 Press Generate — watch the maze grow cell by cell in real time.
  4. 4 Choose a Solver — try different solvers on the same maze to compare behaviour.
  5. 5 Press Solve — the solver explores cells (cyan) then traces the solution (yellow).
  6. 6 Read the stats — the bottom bar shows scanned cells, path length, and efficiency.
Tip: Lower the animation speed to 0.1× to study how the solver frontier expands step by step.

Generators

DFS Long corridors

Recursive backtracker. Carves one deep path, then backtracks to branch. Produces mazes with long winding corridors and relatively few dead-ends.

Style: corridor-heavyBias: directional
Prim's Balanced

Grows a minimum spanning tree from a random seed. Adds the cheapest frontier edge at each step. Creates bushy, branchy mazes with many short dead-ends and even complexity.

Style: dense & branchyBias: centred
Kruskal's Uniform

Randomly merges disjoint cell-sets by removing shared walls. No directional bias. Produces statistically uniform mazes that look symmetrically random.

Style: unbiasedSpeed: fast
Wilson's Truly uniform

Uses loop-erased random walks to connect unvisited cells. Generates a perfectly uniform spanning tree — the gold standard for unbiased mazes, but slow to start.

Style: perfectly unbiasedSpeed: slow start

Solvers

BFS Shortest path

Explores the maze level by level using a queue. Guarantees the absolute shortest path but visits many cells. Great for comparing solver efficiency.

Optimal: yesComplexity: O(V+E)
DFS Fast explore

Dives deep before backtracking using a stack. Finds a path quickly but it may be far from optimal. Produces dramatic, winding solution traces.

Optimal: noComplexity: O(V+E)
A* Guided optimal

Combines BFS's guarantee with a Manhattan-distance heuristic to skip irrelevant cells. Finds the shortest path while scanning far fewer cells than BFS.

Optimal: yesHeuristic: Manhattan
Wall Follower Simple

Keeps one virtual hand on the right wall and follows it to the exit. Intuitive to visualise but only works on simply-connected (no isolated walls) mazes.

Optimal: noLimitation: simple mazes only
Dead-End Filling Visual

Progressively seals all dead-end passages from the outside in. What remains is the solution path. Not a search algorithm — it's maze surgery.

Optimal: yesStyle: elimination
